# PDF-Ready Layout Notes (ATS Friendly)

## 1) Page Setup

- Size: A4 or US Letter (pick one and keep consistent).
- Margins: 1.8-2.2 cm on all sides.
- Length: 1 page (ideal for <8 years experience), max 2 pages.

## 2) Typography

- Recommended fonts: Calibri, Arial, Helvetica, or Times New Roman.
- Font size: 10.5-12 pt body, 13-16 pt section headers.
- Line spacing: 1.15-1.3 for readability.

## 3) Structure

- Single-column layout for best ATS parsing.
- Section order recommendation:
  1. Header + Contact
  2. Professional Summary
  3. Core Skills
  4. Experience
  5. Projects
  6. Publications/Research
  7. Certifications
  8. Education
  9. Volunteer + Organizations

## 4) Writing Rules

- Start bullets with strong action verbs: Led, Built, Designed, Improved, Automated, Deployed.
- Formula per bullet: Action + Context + Tool + Measurable Result.
- Use consistent tense:
  - Present role: present tense
  - Past role: past tense

## 5) ATS Safety Rules

- Do not use tables, text boxes, columns, icons, graphics, headers/footers for key info.
- Do not paste text as image.
- Keep date format consistent: MMM YYYY - MMM YYYY.
- Use full words before abbreviations at least once (e.g., Retrieval-Augmented Generation (RAG)).

## 6) Export to PDF

- Export from Word/Docs as standard PDF (not scanned PDF).
- Re-open PDF and test:
  - Can you select text?
  - Is reading order correct when copy-paste to plain text?

## 7) File Naming

- Use: Firstname_Lastname_CV_AI_Engineer_2026.pdf
- Keep versions: \_v1, \_v2 only if necessary.
